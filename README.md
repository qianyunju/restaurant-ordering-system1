# 黔韵居贵州家常菜点餐系统 - 即开即用版本

## 系统特点

✅ **完全独立**：无需网络连接，无需服务器配置
✅ **即开即用**：直接打开HTML文件即可使用
✅ **数据持久化**：所有数据保存在浏览器本地存储中
✅ **响应式设计**：支持移动端和桌面端浏览器
✅ **功能完整**：支持顾客点餐和管理员管理

## 快速开始

### 方法一：直接打开（推荐）
1. 找到 `index.html` 文件
2. 双击打开文件（会在默认浏览器中运行）
3. 开始使用点餐系统！

### 方法二：使用本地服务器（可选）
如果您想使用本地服务器运行：

```bash
# 使用Python启动本地服务器
python3 -m http.server 8000

# 或者使用Node.js的http-server
npx http-server -p 8000
```

然后在浏览器中访问：http://localhost:8000

## 使用指南

### 顾客使用
1. 点击右上角用户图标，输入姓名登录
2. 在菜单页面浏览菜品，点击"加入购物车"
3. 点击购物车图标查看已选菜品
4. 点击"去结算"，填写桌号和备注
5. 确认支付后完成订单
6. 在订单页面查看订单状态

### 管理员使用
1. 点击右上角用户图标，选择管理员登录
2. 使用默认账号：admin / admin123
3. 在分类管理中添加或编辑菜品分类
4. 在菜品管理中添加、编辑或删除菜品
5. 在订单管理中查看和处理顾客订单
6. 点击"返回顾客端"切换回顾客界面

## 数据管理

### 数据存储位置
所有数据都存储在浏览器的LocalStorage中：
- 用户信息：current_user_v3
- 订单数据：orders_v3
- 菜单数据：menuItems_v3
- 分类数据：categories_v3
- 管理员登录状态：admin_logged_in_v3

### 数据备份
如需备份数据，请在浏览器开发者工具中导出LocalStorage数据。

### 数据重置
如需重置系统数据，请清除浏览器LocalStorage或使用隐私模式。

## 常见问题

### Q: 数据会丢失吗？
A: 不会，数据存储在浏览器本地，除非手动清除浏览器数据。

### Q: 可以在多台设备上使用吗？
A: 可以，但数据是独立的，不会在设备间同步。

### Q: 支持离线使用吗？
A: 完全支持，系统设计为离线优先。

### Q: 如何添加新的菜品分类？
A: 管理员登录后，在分类管理页面添加新分类。

### Q: 图片上传有大小限制吗？
A: 受浏览器LocalStorage限制，建议图片大小不超过2MB。
